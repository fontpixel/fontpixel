# 中日韩书写系统标签与集合图口径

现行规则，2026-09-26 起（`PIPELINE_VERSION` 23）。讨论过程与被否决的方案见
[archive/2026-09-26-cjk-script-labels-discussion.md](../archive/2026-09-26-cjk-script-labels-discussion.md)。

实现：`pipeline/opf/coverage/engine.py`（`SCRIPT_REFERENCE_CHARSETS`、`detect_scripts`）、
`pipeline/opf/coverage/cjk.py`（集合图）、`site/src/lib/rating.ts`（排序）。

## 原则

- 首页"书写系统"标签回答的是"能不能正常书写这门语言"。因此中日韩各用本地区的
  **核心常用表**，阈值取 **98%**。
- GB 2312、Big5、通用规范 8105 全表等"是否达到某个标准"的问题，交给覆盖率筛选和
  徽章处理，不参与书写系统标签。
- 标签判定、覆盖率筛选、集合图和排序使用同一批字表。`test_coverage_picks.py`
  检查每个书写系统的判定字表都出现在筛选下拉框里，并检查各语言的规则文案与代码阈值一致。

## 书写系统标签

同一族内逐个字号判定，取最好的一档（`build.py: merge_scripts`）。

| 书写系统 | 完整 | 不完整 |
|---|---|---|
| 简体中文 | 通用规范汉字表一级字（3,500）≥ 98% | 一级字 10%–98% |
| 繁体中文 | 常用国字标准字体表（甲表，4,808）≥ 98% | 甲表 10%–98% |
| 日文 | `jisx0208-kana` 全部覆盖（JIS X 0208 平假名 83 个、片假名 86 个，以及 ー・，共 171 个），且 JIS X 0208 第一水準漢字 ≥ 98% | 平假名 83 个、片假名 86 个**各** ≥ 95%，第一水準 ≥ 10%，且未达到"完整" |
| 韩文 | KS X 1001 谚文音节（2,350）≥ 98% | 10%–98% |
| 拉丁、西里尔、希腊、阿拉伯、泰文 | 各自参照字表 ≥ 90%（未改动） | 10%–90% |

说明：
- 只有假名、几乎没有汉字（第一水準 < 10%）的字体不带日文标签。
- 韩文只看谚文，不看汉字；集合图里的"韩国"圈展示的是汉字，两者是不同的问题。
- 标签文字仍为"完整 / 不完整"。

## 逐字号判定与标记

2026-09-26 起，目录筛选中与字号相关的条件（字号、墨高、书写系统、字重、间距、覆盖率、包含字符）
必须由**同一个字号**同时满足，字体族才会出现在结果中。以前是各条件分别由任一字号满足即可，
可能出现"18px 能写简体、13px 满足字号条件"就被当成"13px 简体字体"的情况。

- 首页卡片：有上述筛选时，名称右侧显示标记。所有字号都满足时显示双勾，title 为"全部变体"；
  部分满足时显示"勾叉"图标，title 列出满足的字号。
- 详情页：每个书写系统标签后面都有同样的标记，表示哪些字号达到了这个标签。
- 只有一个字号的字体族，卡片和详情页都不显示标记。
- 数据：index.json 的每个字号带 `scripts`、`inkHeight`；多字号族的逐字号覆盖率放在
  `variant-coverage.json`，码位区间文件 `coverage-intervals.bin.gz` 改为逐字号（相同码位的字号共用一组）。
  这两个文件只在用到覆盖率或"包含字符"筛选时才加载，加载前按整个族的最大值判断，也不显示标记。
- 触屏：长按任何带 title 的元素会显示它的内容（`site/src/lib/touchtitle.ts`）。
  带 title 的链接长按时，不再弹出系统的链接菜单。

## 字表文件

- `jp/jisx0208-kana.txt`：新增，171 个。
- `jp/hiragana.txt`、`jp/katakana.txt`：改为 JIS X 0208 的 83、86 个（原为 Unicode 区段 86、90 个）。
  这两张表同时用于 `kana` 徽章和日文"不完整"的 95% 门槛。
- `tw/bopomofo.txt`：改为基本注音 37 个（原为两个 Unicode 区块共 75 个）。
  声调符号 ˉˊˇˋ˙ 不统计：它们是与拉丁文共用的间距修饰字母，纯拉丁字体也常带，覆盖了不能说明支持注音；
  只有声调、没有带调元音等配套字符，单独统计也没有意义。

## 排序

`rating.ts` 的核心覆盖率改用同一批核心表：简体 = 一级字，繁体 = 甲表，
日文 = 0.7 × 第一水準 + 0.3 × `jisx0208-kana`（平假名、片假名各 ≥ 95% 时才计），
韩文 = KS X 1001 谚文。深度加分（depth）的参照表未改动，见
[catalogue-rating.md](catalogue-rating.md)。
