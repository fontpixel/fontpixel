# Canonical licence texts

The text a licensor publishes for each licence, kept here so a font page can
always show the terms it is offered under — plenty of the distributions we
collect from carry only a font file and name the licence in a README or a BDF
comment.

A family's own bundled licence file always wins; these are the fallback, and a
page rendered from one says so. The claim is deliberately narrow: the source we
took the font from shipped no licence file. Whether the author published one
elsewhere we do not know, and the page does not say.

Sources: the SPDX licence list (`spdx/license-list-data`) for the standard
licences; the upstream distribution itself for the project-specific ones —
M+ from the M+ FONTS release bundled with k12x8, Tamsyn from the copy preserved
in sunaku/tamzen-font (the author's own site is gone), ISAS from the COMMENT
block of the Institute of Software's own BDF.

There is deliberately no file for LicenseRef-PublicDomain: a public domain
dedication is a status, not a licence with a text.
