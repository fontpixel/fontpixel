# desc_en: The 87 characters actually needed to write Thai: the 44 consonants, the vowel signs and tone marks, Thai digits, the baht sign, and everyday punctuation. This set matches the Thai portion of TIS-620, Thailand's national standard, and at the same time is exactly the set of assigned characters in the Unicode Thai block U+0E00-0E7F -- the four slots TIS-620 leaves unused, U+0E3B-0E3E, are unassigned in Unicode too. Covering this set and fully supporting Thai are therefore the same thing.
